## 🌐 Live Demo

https://dream-reflection-orpin.vercel.app/

## 📖 Description

Dream Reflection is a modern and responsive personal portfolio website built using HTML, CSS, and JavaScript. It showcases my skills, services, projects, and contact information with a clean and user-friendly interface.

---

## ✨ Features

- Responsive Design
- Modern User Interface
- Hero Section
- About Section
- Skills Section
- Services Section
- Projects Showcase
- Contact Form
- Smooth Scrolling
- Mobile Friendly
- Privacy Policy Page
- Terms & Conditions Page

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

---

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/krisnehakri-alt/Dream-reflection.git
```

Go to the project folder:

```bash
cd Dream-reflection
```

Open `index.html` in your browser.
